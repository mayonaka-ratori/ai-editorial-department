## 段階7 試して直す

- 3社のキーを .env.local に入れ、3人それぞれから本物の返事が返るか確かめる。
  - モデル名（gemini-3.7-flash、gpt-5.6-luna）が正しいかをここで確かめる。違えば環境変数で差し替える。
  - SDKの呼び方（Anthropicの messages.parse と output_config、OpenAIの responses.create の json_schema、Googleの responseSchema と abortSignal）は、入っているSDKの型とは合っている。本物で通すのはここが初めて。
- テスト用の原稿の束（docs/concept.md の12）を `npm run judge-all`（scripts/judge-all.ts）で3人全員に見せ、結果を表にする。
- 判定の割合、引用の正しさ、コメントの平易さ、性格の出方を見て、指示文を直す。
- AIが書いた文章が載らないこと、有名作品がはじかれること、改稿が前回に触れること、を確かめる。
- 「AIっぽく話してもらう」で送ったとき、判定が変わらず言い方だけ変わるかを確かめる。
- 本物のAIが上限額に当たったときのエラーの文を見て、休業の自動切り替えが働くかを確かめる（lib/closure.ts）。
- 読んでいる間の演出の長さを、本物の応答時間に合わせて見直す。
- スマホの実機で通しで確かめる。古めの機種でも動くか。

終わりの確認: 3人の性格の違いが、あなたが見て「わかる」と言える。
