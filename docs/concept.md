# AI編集部「月刊フェーブル」 企画メモ（第2版）

展示会で来場者がスマホで3分ほど遊べる体験アプリの案です。
第1版への回答を反映しました。決まっていないところは末尾にまとめています。

## 1. ひとことで言うと

「AIが読者の小説雑誌」の編集部に、来場者が自分の文章を持ち込む。
AI編集者2名がそれを読んで「うちの読者（AI）にウケるか」を判定し、
巻頭、特集、巻末、別冊のどこに載るかが決まる。
結果はその場でXに投稿でき、載った作品は架空の雑誌「月刊フェーブル」の表紙に並ぶ。

## 2. 「AI向け」とは何か

このアプリでの「AI向け」は、いわゆるAI臭い文章のことではありません。

> AI向けの文章とは、AIが自分では書けない文章のこと。

読者であるAIはすでにほとんどの文章を読んでいて、ありふれた文章なら自分で書けます。
自分で書けるものを読んでも面白くない。AI読者が読みたいのは「自分には書けないもの」です。

これで次のことが自然に決まります。

- なめらかで無難な、いかにもAIが書いたような文章は載らない。
  理由は「うちの読者なら自分で書けるから」。
- 有名作品のコピペは載らない。理由は「うちの読者はもう読んでいるから」。
- 下手でも、その人にしか書けない一文があれば載りうる。

「AIが書けないものとは何か」には答えが複数あるので、考えの違う編集者を2名置きます。

### 編集者A 曽根蔵人（そねくろうど）

- 考え方: AIが書けないのは「次の一文が予測できない文章」。
- 見るところ: 決まり文句がないか。その人にしか出てこない具体的な言葉があるか。
  途中で先が読めてしまわないか。要約しても何も減らない文章ではないか。
- 好きなもの: 変な固有名詞、妙に細かい数字、話が変な方向に曲がるところ。
- 嫌いなもの: 「心温まる」「かけがえのない」など、どこかで見た言い回し。きれいにまとまったオチ。
- 性格: 口数が少なくて厳しい。ほめるときは一文だけ引用して「ここ」とだけ言う。
- 口ぐせ: 「読者はもう全部読んでます」

### 編集者B 小布施ハイク（おぶせはいく）

- 考え方: AIが書けないのは「体と時間がある人にしか書けない文章」。
- 見るところ: 寒い、痛い、腹が減った、待たされた、忘れた、後悔した、といった
  体や時間の実感があるか。特定の日の特定の出来事か。それとも一般論か。
- 好きなもの: 冷めたごはんの話、バスを待っている時間の話、何も起きない火曜日の話。
- 嫌いなもの: うまく見せようとして飾った文章。抽象的な感想。人生訓。
- 性格: 人当たりがよく、よくしゃべる。「これ、実際にあったんですか」と聞きたがる。
- 口ぐせ: 「うちの読者には体がないんで」

### 2人の意見が割れる例

| 持ち込み原稿 | 曽根 | 小布施 |
|---|---|---|
| 実験的で奇妙な短文。体の話は出てこない | 巻頭 | 別冊「面白いけど体温がない」 |
| 今朝のコンビニでの出来事を淡々と書いた日記 | 巻末「先が読める」 | 巻頭 |
| 生成AIっぽい、なめらかで無難な小話 | 次号待ち | 次号待ち |
| 具体的で予想外の細部がある実体験 | 巻頭 | 巻頭 |

### 話し方の温度

2人ともAIらしく、落ち着いていて丁寧。感嘆符はほぼ使わない。
けなすときも人格ではなく文章の話しかしない。
励ますときも大げさにせず「次はこういうものを」と具体的に言う。

## 4. 判定は合否ではなく「どこに載るか」

不採用以外に段階をつけます。上から順に良い結果です。

| 枠 | 意味 | 表紙での扱い |
|---|---|---|
| 巻頭 | 即戦力。今すぐ載せたい | 表紙の一番大きい位置に作者名と作品名 |
| 特集 | 今月の特集ページに | 表紙の中段に中くらいの文字 |
| 巻末 | 載せる。ただし末尾に | 表紙の下段に小さい文字で作者名のみ、または作品名のみ |
| 別冊 | 本誌ではなく「別冊フェーブル」に | 本誌の表紙には載らない。別冊の表紙に載る |
| 次号待ち | 今回は見送り。次の新作を待っています | 表紙には載らない。編集部からの手紙だけ渡す |

### 2人の判定の合わせ方（案）

- 2人とも巻頭なら巻頭。巻頭は満場一致でしか取れない。
- それ以外は高いほうの枠。ただし片方だけの巻頭は特集に下がる。
- 次号待ちは2人とも見送りのときだけ。
- 高いほうを出した編集者が「推薦者」として表紙に名前が添えられる。
  例: 『靴下が片方だけ』 作: ○○ 推薦: 曽根蔵人

高いほうを取るのは、来場者が悲しくならないためと、
「どちらが推したか」が表紙に残るとその編集者の個性が伝わるためです。

## 5. 体験の流れ（目標3分）

ブースには説明役が1人いるだけなので、来場者は自分のスマホで遊びます。
診断メーカーのように、URLを開いて入れて結果が出て、そのまま投稿できる形にします。
イベント当日はSNSにもURLを出すので、会場にいない人も遊べます。

1. 受付（10秒）
   ブースで説明を聞き、QRコードを読み取る。
   「月刊フェーブル編集部です。持ち込み原稿をどうぞ」と表示。
2. 原稿の持ち込み（60秒）
   ペンネームを入力し、文章を貼り付ける。
   自分のXの投稿やブログの一部でよい。目安は3行から10行。
   お題はなし。貼り付けだけに絞る（要確認、詰めたいところ参照）。
3. 編集者が読む（20から30秒）
   2人が読んでいる様子を見せる。ここでAIの応答待ちを隠す。
   「曽根が2回目を読んでいます」のような表示。
4. 編集会議（30秒）
   2人が短く言い合う。ここが一番の見せ場。
   例:
   曽根「3行目の『靴下が片方だけ濡れてた』はいい。あとは全部読めた」
   小布施「読めたっていいじゃないですか。濡れた靴下、うちの読者は履けないんですよ」
   最後にどこに載るかが決まり、判子が押される演出。
5. 結果と投稿（30秒）
   結果カードが出る。載った枠、作品名、推薦者、2人のひとこと。
   「Xに投稿」ボタンで、イベントの告知ツイートを引用する形の投稿文が用意される。
   同時に、会場のモニターの表紙に作者名と作品名が追加される。

## 6. 作品名

タイトルのない文章が多いはずなので、編集部がタイトルをつけます。
推薦者がつける。2人とも巻頭なら2案出して来場者が選ぶ。

## 7. 表紙

- 文字はテンプレートに流し込む方式にする（HTMLかCanvasで組む）。
  画像生成AIに文字を書かせると日本語が崩れるため。
- 表紙は2種類。
  a. 会場で育つ1冊。載った作品が順に追加されていく。ブースのモニターに出す。
  b. 自分だけの1枚。結果カードとして手元に残り、投稿にも使う。
- 別冊は「別冊フェーブル」として別の表紙を持つ。
- 載る作品が増えすぎたら号を分ける。例えば30作で1号にして「第2号」に切り替える。
  当日の終わりに「本日は第4号まで出ました」と言える。

## 8. 背景（部屋）

- 編集者ごとに違う部屋を用意する。曽根の部屋と小布施の部屋。
- まずは固定の絵で成立させる。
- 動く背景（TRIPOなどで作った3D）は別途検討。あると豪華だが、なくても体験は成立する。

## 9. 保存するもの

- 保存する: 作品名、作者名（ペンネーム）、載った枠、推薦者、日時。
- 保存しない: 本文。
- 要確認: 編集者のひとことと引用した一文。本文の一部なので扱いを決める必要がある。
  （詰めたいところ1）

## 10. 守り

- 有名作品のコピペ: 編集者が気づいて「うちの読者はもう読んでます」と見送る。仕様でありネタ。
- 不適切な内容: 表紙に載せる前に判定を挟む。引っかかったら表紙には載せず、手元の結果だけ返す。
  ペンネームも同じ判定を通す。
- 空欄、極端に短い: 「一文でもいいので」と促す。
- 一般公開するので、回数制限と費用の上限を置く。
- 個人情報: 表紙に載るのはペンネームと作品名だけ。本文は保存しない。

## 11. 詰めたいところ（第2版）

1. 引用した一文と編集者のひとことを保存するか。
   結果ページをURLで残す（診断メーカー方式）なら何かしら保存が要る。
   案: 結果画像だけを保存し、文字データとしては保存しない。
2. 2人の判定の合わせ方は「高いほう」でよいか。巻頭だけ満場一致、でよいか。
3. 貼り付けだけに絞ってよいか。手ぶらの人向けに「その場で3行書く」を残すか。
4. 引用元にするイベントの告知ツイートは事前に用意できるか。URLが要る。
5. ブースにモニターかiPadはあるか。表紙を出す場所。
6. 結果ページのURLはいつまで生かすか。
7. 一般公開の範囲。当日限定か、展示後も遊べるか。費用に関わる。
8. 名前の最終決定。曽根蔵人と小布施ハイクでよいか。
