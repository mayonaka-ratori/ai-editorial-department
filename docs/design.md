# 見た目と演出（第4版。2026年9月22日の画面に合わせた）

「ネットワークの中にある編集部」を土台に、雑誌を3誌に分け、各社の色をはっきり出す形です。

## 1. ひとことで言うと

> ネットワークの中にあるAI編集部。雑誌が3つあり、それぞれ色がまったく違う。

- 入口と編集部の共通の部分は、白と水色と深い紺の、明るくて清潔な近未来の空間。
- 雑誌を選んだ瞬間に、画面全体がその雑誌の色に変わる。ここが一番の見せ場。
- 判定は六角形の印が光って確定する。表紙は宙に浮かんでいる。

## 2. 共通の部分の見た目（入口、雑誌を選ぶ画面、管理）

| 役割 | 色 |
|---|---|
| 地 | 深い紺（#070b16）。光の粒が漂う |
| 文字と線 | 白と水色（#35d6ff） |
| ボタン | 水色の帯。角を斜めに切る |

- 入口の真ん中に、光る六角形。中の文字は「AI」。周りを3つの輪が回る。
- 日本語はZen Kaku Gothic New。英字と数字はRajdhani。

## 3. 3誌の見た目

### 季刊フェーブル（蔵人、Claude）　生成りの紙と橙

表紙は、届いた絵（生成りの紙に橙の罫線、橙の四角の中で本の上に座って本を読む炎の子）を地にする。絵は public/covers/kurodo/bg.webp（832×1248、2対3）。
題字「季刊フェーブル」は太い明朝（Shippori Mincho）で上に大きく。下の段に、縦書きで巻頭、特集、巻末の作品名と作者名を並べる。完成イメージは届いた絵の通り。

空間と動きと印の色。Claudeのマスコットの色（暖かい橙）と黒。

- 空間: 黒に近い闇の中に、光る文字の列が柱のように奥まで並ぶ。柱は橙にほのかに光る。静か。
- 動き: 光の粒がゆっくり昇るだけ。ウィンドウは揺れない。
- 印の色: 橙。

### GEMINI（ジェミニ。二ナ、Gemini）　色とりどり

表紙は、届いた3枚の絵（パステルの水彩の地、GEMINIのロゴ、リボンに乗ったマスコット）を重ねて作る。
絵は public/covers/nina/ にある。3枚とも同じ大きさ（1328×1760）で、そのまま重ねる。
作品名は、左の縦の列に巻頭、右の縦の列に特集、下の帯に巻末を置く。文字には白い光の縁を付けて、絵の上でも読めるようにする。

空間と動きと印の色。Googleの4色（青、赤、黄、緑）とGeminiの青から紫のグラデーション。

- 空間: 白から薄い水色の明るい空間に、色とりどりの四角いウィンドウが何枚も浮いて揺れている。にぎやか。ウィンドウは画面の上30%より下には置かず、文字の後ろで薄くする。
- 動き: ウィンドウが上下に揺れる。巻頭のときは色の粒が一斉に上がる。
- 印の色: 青から紫のグラデーション。

### 月刊アストラ（ソル、GPT）　宇宙

表紙は、届いた絵（太陽、月、地球と軌道の線が入った宇宙）を地にする。絵は public/covers/sol/bg.webp（1024×1536、2対3）。
題字「月刊アストラ」は1文字ずつ色の違う明朝。右上に号。左下に巻頭の作品名を大きく、特集を3行、一番下に巻末の帯（『作品名』作者名）。完成イメージは届いた絵の通り。

3誌とも、絵の雰囲気を壊さないように、飾りの英語や説明の文字は表紙に置かない（2026年9月21日に決めた）。表紙に置く文字は、題字、号、巻頭・特集・巻末の作品名と作者名だけ。

空間と動きと印の色。GPTの世代の名前（Astra、Sol、Terra、Luna）から、宇宙の色。

- 空間: 深い宇宙の紺。星が散り、遠くに太陽、地球、月が小さく並んでいる。整った格子の線が奥に向かって消えていく。
- 動き: 星がまたたくだけ。格子は動かない。
- 印の色: 銀白。

## 4. 体験の山場

### 山場1 雑誌を選ぶと色が変わる

雑誌を選んだ瞬間、画面全体がその雑誌の色に切り替わる。橙と黒、色とりどり、宇宙。
「3つの雑誌は本当に違う」を、文章を読む前に色で伝える。

### 山場2 送る

「送る」を押すと、入力欄の文章が単語ごとの小さな四角に分かれ、画面の上に開いた光の輪に吸い込まれる。
「UPLOADING 0%」から「100%」まで上がる。2秒。

### 山場3 読まれていく

編集者の空間に、単語の四角が並んでいる。順に白く光って上に消えていく。
画面の下に大きな光の輪が息をするように広がり、「READER IS HERE」と小さく出る。
編集者ごとに違う「読んでいる間」の文が出る。AIの応答待ちをここで埋める。

### 山場4 印が確定する

コメントが1文字ずつ出たあと、六角形の印が大きく光りながら現れ、縮んで定まる。
その瞬間に画面が白く光り、少し揺れ、スマホが震える（Androidのみ）。
巻頭のときだけ印が金色になる。

### 山場5 表紙に載る

小さな表紙が下からせり上がり、あなたの作品名が滑り込む。
同時にブースの大画面の表紙にも同じ作品名が現れて光る。

### 山場6 大画面

奥に消えていく格子の床の上に、3誌の表紙が並んで浮かんでいる。真ん中が大きく、両脇が少し小さい。
時間で真ん中が入れ替わる。新しい作品が枠に入ると作品名が光り、押し出された作品は静かに消えて下の目次に移る。
表紙の下でその雑誌の目次が横に流れる。右下に「組版中」、発行後は「発行」。

## 5. 3Dをどこまで使うか

スマホでは3Dのライブラリを使わない。空間は奥、中、手前の3層に分けてCSSで描く。
パソコンではマウスの位置で3層が少しずれる。スマホの傾きセンサーは使わない（iOSで許可のダイアログが出て、体験の邪魔になるため）。

大画面も今はCSSの3Dで、格子の床の上に3誌の表紙を浮かべている。
three.jsにして、床の格子、光の粒、表紙の反射を豪華にするかは、まだ決めていない（docs/plan.md）。

## 6. 編集者の見せ方

- 雑誌を選ぶ画面には、3誌の表紙が横に並ぶ。真ん中が大きく、左右は小さい（docs/wireframes.md の2）。
  下に選んでいる雑誌の札。左に顔、頭の上にAIのしるしの光る輪。雑誌名、編集者名、口ぐせ、見るところ、小さく「CORE: Claude」。
- 選ぶと、その雑誌の色の空間に入る。編集者は上のほうに顔だけ見えていて、吹き出しで話す。
- 顔は待ち、読み、判定の3ポーズ。二ナだけ両手を上げたポーズを追加。絵が届くまでは、名前の1文字（蔵、二、ソ）を丸の中に出している。

## 7. 結果カード（Xに貼られる画像）

横長の1枚（1200×630）。その雑誌の色の地に、左上に「AI編集部」と雑誌名、左に六角形の印、
右に作品名、作者名と推薦した編集者、引用の一文（40字まで）。下に雑誌名と編集者名、「#AI編集部」。巻頭だけ印が金。
編集者の顔の絵が届いたら、顔も入れる。
