# 画面のワイヤーフレーム（第3版。見た目は docs/design.md 第3版に従う）

スマホで遊ぶ画面が中心です。表紙の画面だけはブースのMacBookで表示します。
枠の中は画面のおおまかな配置で、細かい見た目はあとで決めます。

画面の一覧。

| 番号 | 画面 | URL | 誰が見るか |
|---|---|---|---|
| 1 | 入口 | / | 来場者のスマホ |
| 2 | 雑誌を選ぶ | /editors | 来場者のスマホ |
| 3 | 原稿を持ち込む | /submit?editor=kurodo | 来場者のスマホ |
| 4 | 読んでいる間 | （3の画面の上に重なる） | 来場者のスマホ |
| 5 | 結果 | /r/{結果の番号} | 来場者のスマホ、投稿を見た人 |
| 6 | 表紙（3誌） | /cover | ブースのMacBook、来場者のスマホ |
| 7 | 目次 | /toc | 同上 |
| 8 | 受付終了 | （1と3の代わりに出る） | 来場者のスマホ |
| 9 | 管理 | /admin | あなただけ |
| 10 | 自分の結果の一覧 | /mine | 来場者のスマホ |

矢印で流れを書くとこうなります。

```
入口 → 雑誌を選ぶ → 原稿を送る → 読んでいる間 → 結果 → Xに投稿
                                                      ↘ 表紙を見る
                                                      ↘ 別の雑誌に送る（2に戻る）
```

---

## 1. 入口（/）

```
+----------------------------------+
|                                  |
|        （光る六角形。中に AI）    |
|                                  |
|          AI編集部                |
|   AIが読む小説雑誌を作っています  |
|                                  |
|  ここはAIが読者の小説雑誌の       |
|  編集部です。雑誌は3つ。          |
|  あなたの文章を送ると、           |
|  AI編集者が「うちの読者に         |
|  ウケるか」を判定します。         |
|                                  |
|  お願い                          |
|  ・送った文章は保存しません       |
|  ・作品名と作者名は表紙に載ります |
|  ・他の人の文章は送らないで       |
|  ・本日限り、合計3000回まで       |
|                                  |
|  [ 編集部に入る ]                |
|                                  |
|  今日の表紙を見る →  残り 2,713回 |
+----------------------------------+
```

- 「編集部に入る」を押すと2へ。
- 受付が終わっていたら、この画面の代わりに8が出る。

## 2. 雑誌を選ぶ（/editors）

```
+----------------------------------+
|  どの雑誌に送りますか             |
|                                  |
|  +----------------------------+  |
|  | 季刊フェーブル   （橙と黒）  |  |
|  | (顔) 蔵人                  |  |
|  |  「読者はもう全部読んでます」|  |
|  |  見るところ: 次の一文が予想できるか |
|  |                中身: Claude|  |
|  +----------------------------+  |
|  +----------------------------+  |
|  | GEMINI （色とりどり） |  |
|  | (顔) 二ナ                  |  |
|  |  「うちの読者には体がないんで！」|
|  |  見るところ: 体と時間の実感があるか |
|  |                中身: Gemini|  |
|  +----------------------------+  |
|  +----------------------------+  |
|  | 月刊アストラ     （宇宙）    |  |
|  | (顔) ソル                  |  |
|  |  「これ、誰に向けて書きました？」|
|  |  見るところ: 誰か1人に向けて書かれているか |
|  |                中身: GPT   |  |
|  +----------------------------+  |
|                                  |
|  ← 戻る                          |
+----------------------------------+
```

- 3つとも、その雑誌の色で縁取る。押すと画面全体がその雑誌の色に変わって3へ。
- 休業中の雑誌は灰色になり「本日は休業です」と出る。押せない。

## 3. 原稿を送る（/submit?editor=kurodo）

背景が、選んだ雑誌の色の空間になる。

```
+----------------------------------+
| (雑誌の色の空間が背景)            |
|  (顔) 蔵人                      |
|  「原稿をどうぞ。」              |
|                                  |
|  ペンネーム                      |
|  [                    ] 10字まで |
|                                  |
|  原稿                            |
|  +----------------------------+  |
|  |                            |  |
|  |                            |  |
|  |                            |  |
|  |                            |  |
|  +----------------------------+  |
|  0 / 1000字   （20字以上）       |
|                                  |
|  何を書けばいいかわからないときは |
|  [今朝食べたもの] [最後に待たされた場所]|
|  [捨てられない物]                |
|                                  |
|  [ 蔵人に送る ]                  |
|                                  |
|  ← 別の雑誌にする                |
+----------------------------------+
```

- 原稿の欄は、貼り付けても、その場で書いてもよい。
- お題のボタンを押すと、原稿の欄の上に「お題: 今朝食べたもの」と出るだけ。本文には入れない。
- 20字未満か1000字超だとボタンが押せない。理由を欄の下に出す。
- 押すとすぐ4に切り替わる。

## 4. 読んでいる間（3の上に重なる）

```
+----------------------------------+
| (雑誌の色の空間、少し暗くなる)    |
|                                  |
|         (顔、少し動く)           |
|                                  |
|      慎重に読んでいます          |
|          ・・・                  |
|                                  |
|                                  |
+----------------------------------+
```

- 表示の文は編集者ごとに3つ用意し、3秒ほどで切り替える。
  蔵人: 「慎重に読んでいます」「2回目を読んでいます」「言い方を考えています」
  二ナ: 「素晴らしい原稿を読んでいます！」「関連情報を調べています（調べなくていい）」「話を戻しています」
  ソル: 「読んでいます」「要点を2つにまとめています」「結論から書いています」
- 混んでいるときは「前に3人います。少しお待ちください」と出て、自動で待つ。
- 30秒たっても返らないときは「時間がかかっています」に変わり、60秒で「もう一度」ボタンが出る。
- 編集者側のAIが落ちているときは「蔵人は今、手が離せないようです。別の編集者に見せますか」と出る。

## 5. 結果（/r/{結果の番号}）

上から順に、少しずつ出てくる。引用、コメント、判子、作品名、次のお願い、の順。

```
+----------------------------------+
| (雑誌の色の空間が背景)            |
|  (顔) 蔵人が読みました           |
|                                  |
|  引用                            |
|  「飲まないまま持って帰った」     |
|                                  |
|  先に言っておくと、終電を逃して   |
|  漫喫に泊まる話は、うちの読者は   |
|  もう何度も読んでいます。         |
|  ただ、最後の「飲まないまま       |
|  持って帰った」は、そうなるとは   |
|  思いませんでした。ここがいいです。|
|  （中略）                        |
|  だから特集にします。             |
|                                  |
|        ┌────────┐                |
|        │  特 集  │ ← 判子       |
|        └────────┘                |
|                                  |
|  作品名 『飲まないまま』          |
|  作者   終電のがし               |
|  掲載   今は季刊フェーブルの      |
|         特集に載っています        |
|                                  |
|  次は: 今回のように、理由を       |
|  書かないで終わる話をもう1本。    |
|                                  |
|  二ナ「蔵人さんが特集を出すのは   |
|  珍しいです！高い評価ですよ！」   |
|  ソル「私も同じくらいの評価です。」|
|                                  |
|  [ Xに投稿する ]                 |
|  [ 表紙を見る ]                  |
|  [ 別の雑誌に送る ]              |
|                                  |
|  この結果のURL: fable.example/r/ab12|
+----------------------------------+
```

- 「Xに投稿する」を押すと、Xの投稿画面が開き、文が入った状態になる。
  文: 「AI編集部の季刊フェーブルに持ち込んだら、蔵人が特集にしてくれました。」
  次の行に、コメントの中の「うちの読者」の一文（40字以内）。次の行に「作品名『飲まないまま』 #AI編集部」。
  そのあとに、この結果のURLと、告知ツイートのURLが付く。
  注意: Xは告知ツイートのURLがあると引用ツイートとして出し、結果のURLの画像カードは出ない。どちらを取るかは docs/concept.md の「まだ決めていないこと」。
- 結果のURLを開くと、投稿に画像が付く。画像は判子と作品名と作者名と編集者の顔が入った1枚。
- 本文はこの画面にも出さない。引用の一文だけ。
- 「別の雑誌に送る」を押すと2に戻る。同じ原稿はもう一度貼る必要がある（保存していないため）。
  ただし、その端末の中には残しておいて、貼り直さなくて済むようにする。

## 6. 表紙（/cover）

ブースの大画面で全画面表示する。3誌の表紙が並んで浮かんでいる。真ん中が大きい。

```
+--------------------------------------------------+
|  NEW 『毛布いりますか』終電のがし（GEMINI 巻頭）…（流れる）|
|                                                  |
|   +---------+   +--------------+   +---------+   |
|   |季刊     |   | GEMINI |   |月刊     |   |
|   |フェーブル|   |  （色とりどり、 |   |アストラ |   |
|   |（橙と黒、|   |   横書き）     |   |（宇宙、  |   |
|   | 縦書き） |   |  巻頭1 特集3   |   | 横書き） |   |
|   | 巻頭1   |   |  巻末6         |   | 巻頭1   |   |
|   | 特集3   |   |               |   | 特集3   |   |
|   | 巻末6   |   |               |   | 巻末6   |   |
|   +---------+   +--------------+   +---------+   |
|                                                  |
|  目次（真ん中の雑誌の全員、ゆっくり流れる）        |
|  [QR: 持ち込みはこちら]    2026年10月号  組版中    |
+--------------------------------------------------+
```

- 10秒ごとに自動で更新する。表紙に入った作品は1回光り、目次に下がった作品は表紙から静かに消える。
- 真ん中の雑誌は30秒ごとに入れ替わる。
- 右下に「組版中」と出る。発行したら「発行」に変わり、それ以降は変わらない。
- スマホで開いたときは、3誌を横に切り替えて見る。表紙の下にその雑誌の目次が縦に並び、自分の名前を探せる。

## 7. 目次（/toc）

作者名と作品名の一覧。新しい順。検索の欄で自分のペンネームを探せる。
雑誌ごとに分かれている。表紙に載っている作品には枠（例: 特集）が添えてある。

## 9. 管理（/admin）

合言葉を入れると開く。あなたしか使わない。

```
+----------------------------------+
|  管理                            |
|                                  |
|  受付      [受付中] / [受付終了] |
|  上限回数  [3000]  今日 287回    |
|                                  |
|  告知ツイートのURL               |
|  [https://x.com/....        ]    |
|  [保存]                          |
|                                  |
|  編集者                          |
|  季刊フェーブル 蔵人 [出勤]/[休業] 今日 98回  エラー 0回 |
|  GEMINI 二ナ [出勤]/[休業] 今日 121回 エラー 2回 |
|  月刊アストラ  ソル [出勤]/[休業] 今日 68回  エラー 0回 |
|                                  |
|  最近の結果                      |
|  13:42 二ナ 巻頭 『毛布いりますか』終電のがし [表紙から外す] |
|  13:41 蔵人 巻末 『失敗のほう』夕焼け        [表紙から外す] |
|  ...                             |
|                                  |
|  発行  [表紙を固める]            |
+----------------------------------+
```

- 「表紙から外す」は、変な名前や内容が表紙に出てしまったときの手動の逃げ道。
  結果のページは残るが、表紙からは消える。
- ここは見た目にこだわらない。動けばよい。

## 第3版で変わったこと（2026年9月21日、実装済み）

ペルソナでの見直し（docs/persona-review.md）と、UIの更新プランの7つを入れた。

1. 雑誌を選ぶ画面は、文字の枠ではなく3誌の表紙を並べる。真ん中が大きく、左右は小さい。左右に動かすか横の表紙を押すと入れ替わり、真ん中の表紙か下のボタンを押すと送る画面へ。表紙は350px幅で組んでから縮めるので、小さくても作品名の折り返しが変わらない。
2. 結果の画面で、コメントが1文字ずつ出ている間は「画面をタップすると、全部出ます」の案内が出る。どこをタップしても全部出て、判定の印が押される。
3. 結果の画面の一番上の行動が「書き直して、もう一度〇〇に送る」。押すと送る画面に戻り、前の原稿（この端末に残している下書き）が入り、上に「〇〇からの頼み」と前回の作品名と判定が出る。同じ文章のままは送れない。ボタンは「〇〇に送る（2稿目）」。
4. 表紙の上で自分の作品が光り、「あなた」の印が付く。目次でも同じ印。3誌の切り替えボタンにも、自分の作品がある雑誌に点が付く。表紙を開くと、自分が最後に送った雑誌が最初に出る。
5. 入口に「自分の結果を見る（3件）」の入口。押すとこの端末で送ったものの一覧（/mine）が出る。
6. 書体（Zen Kaku Gothic New、Rajdhani、Shippori Mincho）はアプリに同梱した。Googleの読み込みはしない。
7. 入口の説明は1行。「選ぶ、送る、載る」の3つの段を置き、お願いの4つは小さい文字の1段落にした。

ペルソナからの9つ。

- 判定の印の下に一言添える。「巻末: 載ります。表紙の下のほうです。」
- 結果に「画像を保存する」「リンクをコピー」を置く。共有ができる端末では「共有する」も出る。
- 「下がることがあります」の後ろに「目次には残ります」を付ける。
- 同じ端末からは1時間に7回まで（5回から変更）。
- 理由の札「AIが書いたようだ」を「うちの読者にも書けそうだ」に変えた。
- 送る画面に「長い文章なら、一部だけ貼っても構いません。」を添える。
- 巻末の帯は3誌とも同じ形（「巻末」の見出しと『作品名』作者名の横並び）。フェーブルは題字のすぐ下、GEMINIとアストラは下のほう。
- Xの投稿文に、編集者のコメントから「うちの読者」の話をしている短い一文を入れる。
- 表紙の作品名は、9字以上と13字以上で文字を小さくして、途中で折れないようにした。

## 絵が要るもの

docs/image-prompts.md（第3版）の通り。顔と空間の絵が届くまでは、色と形だけの仮の絵で動かす。
