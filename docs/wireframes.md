# 画面のワイヤーフレーム（第1版）

スマホで遊ぶ画面が中心です。表紙の画面だけはブースのMacBookで表示します。
枠の中は画面のおおまかな配置で、細かい見た目はあとで決めます。

画面の一覧。

| 番号 | 画面 | URL | 誰が見るか |
|---|---|---|---|
| 1 | 入口 | / | 来場者のスマホ |
| 2 | 編集者を選ぶ | /editors | 来場者のスマホ |
| 3 | 原稿を持ち込む | /submit?editor=kurodo | 来場者のスマホ |
| 4 | 読んでいる間 | （3の画面の上に重なる） | 来場者のスマホ |
| 5 | 結果 | /r/{結果の番号} | 来場者のスマホ、投稿を見た人 |
| 6 | 表紙 | /cover | ブースのMacBook、来場者のスマホ |
| 7 | 過去の号 | /cover/3 | 同上 |
| 8 | 受付終了 | （1と3の代わりに出る） | 来場者のスマホ |
| 9 | 管理 | /admin | あなただけ |

矢印で流れを書くとこうなります。

```
入口 → 編集者を選ぶ → 原稿を持ち込む → 読んでいる間 → 結果 → Xに投稿
                                                      ↘ 表紙を見る
                                                      ↘ 別の編集者に見せる（2に戻る）
```

---

## 1. 入口（/）

```
+----------------------------------+
|                                  |
|         月刊フェーブル            |
|       AIのための小説雑誌          |
|                                  |
|  ここはAIが読者の小説雑誌の       |
|  編集部です。                     |
|  あなたの文章を持ち込むと、       |
|  AI編集者が「うちの読者に         |
|  ウケるか」を判定します。         |
|                                  |
|  お願い                          |
|  ・送った文章は保存しません       |
|  ・作品名と作者名は表紙に載ります |
|  ・他の人の文章は送らないで       |
|  ・本日限り、合計3000回まで       |
|                                  |
|  [ 持ち込む ]                    |
|                                  |
|  今日の表紙を見る →              |
|  残り 2,713回                    |
+----------------------------------+
```

- 「持ち込む」を押すと2へ。
- 残り回数は目立たせない。小さく出す。
- 受付が終わっていたら、この画面の代わりに8が出る。

## 2. 編集者を選ぶ（/editors）

```
+----------------------------------+
|  誰に見せますか                   |
|                                  |
|  +----------------------------+  |
|  | (顔)  蔵人               |  |
|  |       そね くろうど        |  |
|  |  「読者はもう全部読んでます」|  |
|  |  見るところ:               |  |
|  |  次の一文が予想できるか     |  |
|  +----------------------------+  |
|  +----------------------------+  |
|  | (顔)  二ナ               |  |
|  |       じぇみ にな          |  |
|  |  「うちの読者には体がないんで！」|
|  |  見るところ:               |  |
|  |  体と時間の実感があるか     |  |
|  +----------------------------+  |
|  +----------------------------+  |
|  | (顔)  ソル               |  |
|  |       あすとら そる        |  |
|  |  「これ、誰に向けて書きました？」|
|  |  見るところ:               |  |
|  |  誰か1人に向けて書かれているか|  |
|  +----------------------------+  |
|                                  |
|  ← 戻る                          |
+----------------------------------+
```

- 名前の札に、どの会社のAIかは書かない。わかる人にはわかる。
  ただし、札の下に小さく「中身: Claude」のように出すかどうかは要相談。
- 休業中の編集者は札が灰色になり「本日は休業です」と出る。押せない。

## 3. 原稿を持ち込む（/submit?editor=kurodo）

背景が、選んだ編集者の部屋になる。

```
+----------------------------------+
| (部屋の絵が背景)                  |
|  (顔) 蔵人                      |
|  「原稿をどうぞ。」              |
|                                  |
|  ペンネーム                      |
|  [                    ] 10字まで |
|                                  |
|  原稿                            |
|  +----------------------------+  |
|  |                            |  |
|  |                            |  |
|  |                            |  |
|  |                            |  |
|  +----------------------------+  |
|  0 / 1000字   （20字以上）       |
|                                  |
|  何を書けばいいかわからないときは |
|  [今朝食べたもの] [最後に待たされた場所]|
|  [捨てられない物]                |
|                                  |
|  [ 蔵人に見せる ]                |
|                                  |
|  ← 別の編集者にする              |
+----------------------------------+
```

- 原稿の欄は、貼り付けても、その場で書いてもよい。
- お題のボタンを押すと、原稿の欄の上に「お題: 今朝食べたもの」と出るだけ。本文には入れない。
- 20字未満か1000字超だとボタンが押せない。理由を欄の下に出す。
- 押すとすぐ4に切り替わる。

## 4. 読んでいる間（3の上に重なる）

```
+----------------------------------+
| (部屋の絵が背景、少し暗くなる)    |
|                                  |
|         (顔、少し動く)           |
|                                  |
|      慎重に読んでいます          |
|          ・・・                  |
|                                  |
|                                  |
+----------------------------------+
```

- 表示の文は編集者ごとに3つ用意し、5秒ごとに切り替える。
  蔵人: 「慎重に読んでいます」「2回目を読んでいます」「言い方を考えています」
  二ナ: 「素晴らしい原稿を読んでいます！」「関連情報を調べています（調べなくていい）」「話を戻しています」
  ソル: 「読んでいます」「要点を2つにまとめています」「結論から書いています」
- 混んでいるときは「前に3人います。少しお待ちください」と出て、自動で待つ。
- 30秒たっても返らないときは「時間がかかっています」に変わり、60秒で「もう一度」ボタンが出る。
- 編集者側のAIが落ちているときは「蔵人は今、手が離せないようです。別の編集者に見せますか」と出る。

## 5. 結果（/r/{結果の番号}）

上から順に、少しずつ出てくる。引用、コメント、判子、作品名、次のお願い、の順。

```
+----------------------------------+
| (部屋の絵が背景)                  |
|  (顔) 蔵人が読みました           |
|                                  |
|  引用                            |
|  「飲まないまま持って帰った」     |
|                                  |
|  先に言っておくと、終電を逃して   |
|  漫喫に泊まる話は、うちの読者は   |
|  もう何度も読んでいます。         |
|  ただ、最後の「飲まないまま       |
|  持って帰った」は、そうなるとは   |
|  思いませんでした。ここがいいです。|
|  （中略）                        |
|  だから特集にします。             |
|                                  |
|        ┌────────┐                |
|        │  特 集  │ ← 判子       |
|        └────────┘                |
|                                  |
|  作品名 『飲まないまま』          |
|  作者   終電のがし               |
|                                  |
|  次は: 今回のように、理由を       |
|  書かないで終わる話をもう1本。    |
|                                  |
|  二ナ「蔵人さんが特集を出すのは   |
|  珍しいです！高い評価ですよ！」   |
|  ソル「私も同じくらいの評価です。」|
|                                  |
|  [ Xに投稿する ]                 |
|  [ 表紙を見る ]                  |
|  [ 別の編集者に見せる ]          |
|                                  |
|  この結果のURL: fable.example/r/ab12|
+----------------------------------+
```

- 「Xに投稿する」を押すと、Xの投稿画面が開き、文が入った状態になる。
  文: 「月刊フェーブル編集部に持ち込んだら、蔵人が特集にしてくれました。作品名『飲まないまま』 #月刊フェーブル」
  そのあとに、この結果のURLと、告知ツイートのURLが付く。
- 結果のURLを開くと、投稿に画像が付く。画像は判子と作品名と作者名と編集者の顔が入った1枚。
- 本文はこの画面にも出さない。引用の一文だけ。
- 「別の編集者に見せる」を押すと2に戻る。同じ原稿はもう一度貼る必要がある（保存していないため）。
  ただし、その端末の中には残しておいて、貼り直さなくて済むようにする。

## 6. 表紙（/cover）

ブースのMacBookで全画面表示する。縦長の雑誌の表紙が中央に出る。

```
+--------------------------------------------------+
|                                                  |
|        +----------------------------+            |
|        |  月刊フェーブル   第3号     |            |
|        |  AIのための小説雑誌  2026.10|            |
|        |                            |            |
|        |  巻頭                      |            |
|        |   『毛布いりますか』       |  ← 大きい  |
|        |      終電のがし  推薦: 二ナ |            |
|        |   『傘、まだ』             |            |
|        |      ゆ        推薦: ソル  |            |
|        |                            |            |
|        |  特集                      |            |
|        |   『飲まないまま』 終電のがし|  ← 中     |
|        |   『少しだけ』 わさび       |            |
|        |   『3回』 ゆ               |            |
|        |                            |            |
|        |  巻末                      |            |
|        |   『皆さんへ』本当の自分 ／  |  ← 小     |
|        |   『たたまなくていい』終電のがし|          |
|        |   『失敗のほう』夕焼け      |            |
|        |                            |            |
|        |  別冊フェーブル も発売中 →  |            |
|        +----------------------------+            |
|                                                  |
|  ← 第2号        [QR: 持ち込みはこちら]   別冊 → |
+--------------------------------------------------+
```

- 10秒ごとに自動で更新する。新しく載った作品は1回だけ光る。
- 30作で1号にする。31作目が載ると「第4号」に切り替わり、前の号は7で見られる。
- 右下のQRコードを読むと1が開く。
- 別冊は同じ形の別の表紙で、色が違う。矢印で切り替える。
- スマホで開いたときは、表紙だけが画面いっぱいに出る。

## 7. 過去の号（/cover/3）

6と同じ見た目で、更新されない。上に「第3号（本日13時〜14時）」と出る。

## 9. 管理（/admin）

合言葉を入れると開く。あなたしか使わない。

```
+----------------------------------+
|  管理                            |
|                                  |
|  受付      [受付中] / [受付終了] |
|  上限回数  [3000]  今日 287回    |
|                                  |
|  告知ツイートのURL               |
|  [https://x.com/....        ]    |
|  [保存]                          |
|                                  |
|  編集者                          |
|  蔵人  [出勤] / [休業]   今日 98回  エラー 0回 |
|  二ナ  [出勤] / [休業]   今日 121回 エラー 2回 |
|  ソル  [出勤] / [休業]   今日 68回  エラー 0回 |
|                                  |
|  最近の結果                      |
|  13:42 二ナ 巻頭 『毛布いりますか』終電のがし [表紙から外す] |
|  13:41 蔵人 巻末 『失敗のほう』夕焼け        [表紙から外す] |
|  ...                             |
|                                  |
|  今日の号: 第3号（27作）         |
+----------------------------------+
```

- 「表紙から外す」は、変な名前や内容が表紙に出てしまったときの手動の逃げ道。
  結果のページは残るが、表紙からは消える。
- ここは見た目にこだわらない。動けばよい。

## 絵が要るもの

| 絵 | 枚数 | 仮の案 |
|---|---|---|
| 編集者の顔 | 3枚 | 色違いの丸に名前の1文字 |
| 編集者の部屋 | 3枚 | 色違いの単色の背景 |
| 判子 | 5種類（巻頭、特集、巻末、別冊、次号待ち） | 赤い四角の枠に文字。プログラムで描く |
| 表紙の背景 | 2枚（本誌、別冊） | 色と罫線だけ。プログラムで描く |

顔と部屋の絵が届くまでは仮の案で動かし、あとで差し替える。
