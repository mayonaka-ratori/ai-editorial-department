# 画面のワイヤーフレーム（第4版。2026年9月22日の画面に合わせた。見た目は docs/design.md に従う）

スマホで遊ぶ画面が中心です。表紙の画面だけはブースのMacBookで表示します。
枠の中は画面のおおまかな配置です。細かい見た目は app/globals.css にあります。

画面の一覧。

| 番号 | 画面 | URL | 誰が見るか |
|---|---|---|---|
| 1 | 入口 | / | 来場者のスマホ |
| 2 | 雑誌を選ぶ | /editors | 来場者のスマホ |
| 3 | 原稿を持ち込む | /submit?editor=kurodo | 来場者のスマホ |
| 4 | 読んでいる間 | （3の画面の上に重なる） | 来場者のスマホ |
| 5 | 結果 | /r/{結果の番号} | 来場者のスマホ、投稿を見た人 |
| 6 | 表紙（3誌） | /cover（スマホ）、/screen（ブースの大画面） | 来場者のスマホ、ブースのMacBook |
| 7 | 目次 | /toc（/cover に飛ぶ） | 同上 |
| 8 | 受付終了 | （1と3の代わりに出る） | 来場者のスマホ |
| 9 | 管理 | /admin | あなただけ |
| 10 | 自分の結果の一覧 | /mine | 来場者のスマホ |

矢印で流れを書くとこうなります。

```
入口 → 雑誌を選ぶ → 原稿を送る → 読んでいる間 → 結果 → Xに投稿
                                                      ↘ 表紙を見る
                                                      ↘ 別の雑誌に送る（2に戻る）
```

|  2 送る  自分の文章を貼るか、3行書く |
|  3 載る  判定が出て、表紙に名前が載る |
|                                  |
|  [ 編集部に入る ]                |
|  [ 自分の結果を見る（3件） ]      |

- 受付が終わっていたら、この画面の代わりに8が出る。

## 2. 雑誌を選ぶ（/editors）

```
+----------------------------------+
|  どの雑誌に送りますか             |
|  左右に動かして、真ん中の表紙を   |
|  押すと決まります。               |
|                                  |
|   +--+  +------------+  +--+     |
|   |  |  |            |  |  |     |
|   |左|  |  真ん中の   |  |右|     |
|   |の|  |  雑誌の表紙 |  |の|     |
|   |表|  |  （大きい） |  |表|     |
|   |紙|  |            |  |紙|     |
|   +--+  +------------+  +--+     |
|                                  |
|  +----------------------------+  |
|  | (顔) 季刊フェーブル　蔵人    |  |
|  |  「読者はもう全部読んでます」|  |
|  |  見るところ: 次の一文が予想できるか |
|  |              CORE: Claude  |  |
|  +----------------------------+  |
|  [ 季刊フェーブルに送る ]         |
|                                  |
|  ← 戻る                          |
+----------------------------------+
```

- 3誌の表紙が横に並ぶ。真ん中が大きく、左右は小さい。左右に動かすか横の表紙を押すと入れ替わる。
- 真ん中の表紙か下のボタンを押すと、画面全体がその雑誌の色に変わって3へ。
- 表紙は350px幅で組んでから縮めるので、小さくても作品名の折り返しが変わらない。
- 下の説明は、いま真ん中にある雑誌のもの。「CORE:」は会社名だけか、管理画面の切り替えでモデル名まで出す。
- 休業中の雑誌は灰色になり「本日は休業です」と出る。押せない。

## 3. 原稿を送る（/submit?editor=kurodo）

背景が、選んだ雑誌の色の空間になる。

```
+----------------------------------+
| (雑誌の色の空間が背景)            |
|  (顔) 蔵人                      |
|  「原稿をどうぞ。」              |
|                                  |
|  ペンネーム                      |
|  [                    ] 10字まで |
|                                  |
|  原稿                            |
|  +----------------------------+  |
|  |                            |  |
|  |                            |  |
|  |                            |  |
|  |                            |  |
|  +----------------------------+  |
|  0 / 1000字   （20字以上）       |
|                                  |
|  何を書けばいいかわからないときは |
|  [今朝食べたもの] [最後に待たされた場所]|
|  [捨てられない物]                |
|                                  |
|  [ 蔵人に送る ]                  |
|                                  |
|  ← 別の雑誌にする                |
+----------------------------------+
```

- 原稿の欄は、貼り付けても、その場で書いてもよい。欄の下に「長い文章なら、一部だけ貼っても構いません。」と添える。
- お題のボタンを押すと、原稿の欄の上に「お題: 今朝食べたもの」と出るだけ。本文には入れない。
- その下に見本の原稿のボタンが3つある。見本は1端末1日1回だけで、表紙にも目次にも載らない。1回使うと3つとも押せなくなり「見本は今日はもう使いました」と出る。見本の文章は原稿の欄には入れない。
- 5の「書き直して、もう一度〇〇に送る」から来たときは、前の原稿（この端末に残している下書き）が入り、上に「〇〇からの頼み」と前回の作品名と判定が出る。同じ文章のままは送れない。ボタンは「〇〇に送る（2稿目）」。
- 20字未満か1000字超だとボタンが押せない。理由を欄の下に出す。
- 押すとすぐ4に切り替わる。

## 4. 読んでいる間（3の上に重なる）

```
+----------------------------------+
| (雑誌の色の空間、少し暗くなる)    |
|                                  |
|         (顔、少し動く)           |
|                                  |
|      慎重に読んでいます          |
|          ・・・                  |
|                                  |
|                                  |
+----------------------------------+
```

- 表示の文は編集者ごとに3つ用意し、3秒ほどで切り替える。
  蔵人: 「慎重に読んでいます」「2回目を読んでいます」「言い方を考えています」
  二ナ: 「素晴らしい原稿を読んでいます！」「関連情報を調べています（調べなくていい）」「話を戻しています」
  ソル: 「読んでいます」「要点を2つにまとめています」「結論から書いています」
- 混んでいるときは「前に3人います。少しお待ちください」と出て、自動で待つ。
- 単語の四角は順に光って消え、全部消えたら1秒置いて最初から光らせ直す。結果が来るまで繰り返す。
- 30秒たっても返らないときは「時間がかかっています」に変わり、60秒で「もう一度」ボタンが出る。押すと同じ本文で送り直す。
- 編集者側のAIが落ちているときは「蔵人は今、手が離せないようです。少し待つか、別の雑誌に送ってください。」と出る。

## 5. 結果（/r/{結果の番号}）

上から順に、少しずつ出てくる。引用、コメント、判子、作品名、いまの掲載、次のお願い、の順。

```
+----------------------------------+
| (雑誌の色の空間が背景)            |
|  (顔) 季刊フェーブルの蔵人が      |
|       読みました   [2稿目]        |
|                                  |
|  QUOTE                           |
|  「飲まないまま持って帰った」     |
|                                  |
|  先に言っておくと、終電を逃して   |
|  漫喫に泊まる話は、うちの読者は   |
|  もう何度も読んでいます。         |
|  （中略）                        |
|  だから特集にします。             |
|  画面をタップすると、全部出ます   |
|                                  |
|        ┌────────┐                |
|        │  特 集  │ ← 六角形の印 |
|        └────────┘                |
|  特集: 表紙に載ります。……        |
|                                  |
|  TITLE 『飲まないまま』           |
|  作: 終電のがし　推薦: 蔵人       |
|                                  |
|  NOW 今は季刊フェーブルの特集に   |
|      載っています。前回より12点   |
|      上がりました。               |
|                                  |
|  次は: 今回のように、理由を       |
|  書かないで終わる話をもう1本。    |
|  [理由の札] [理由の札]            |
|                                  |
|  (二)二ナ「蔵人さんが特集を……」  |
|  (ソ)ソル「私も同じくらいの……」  |
|                                  |
|  （小さな表紙がせり上がり、       |
|    作品名が入る）                 |
|                                  |
|  [ 書き直して、もう一度蔵人に送る ] |
|  [ Xに投稿する ]                 |
|  [ 表紙を見る ] [ 別の雑誌に送る ] |
|  画像を保存する リンクをコピー 共有する |
|                                  |
|  （この結果のURL）                |
+----------------------------------+
```

- コメントが1文字ずつ出ている間は「画面をタップすると、全部出ます」の案内が出る。どこをタップしても全部出て、判定の印が押される。
- 印の下の一言は、判定といまの掲載に合わせて変える。判定が巻末でも表紙が埋まって目次に下がっているときは「表紙に推薦されましたが、今は目次に名前が載っています」と出し、すぐ下のNOWと食い違わないようにする。
  「下がることがあります」と書くときは、後ろに「目次には残ります」を付ける。
- NOWは開くたびにいまの掲載を取り直す。前の作品のほうが点数が高いときや、表紙と目次に出せない言葉があったときは、その理由を書く。
- 「2稿目」の印と、前回より点数が上がったか下がったかは、書き直したときだけ出る。見本のときは「見本」の印が出て、書き直しと投稿と共有のボタンは出ない。
- 「Xに投稿する」を押すと、Xの投稿画面が開き、文が入った状態になる。文の形は docs/tech.md の9。
  例:
  「AI編集部の季刊フェーブルに持ち込んだら、蔵人が特集に選んでくれました。
  蔵人「うちの読者は、自分では書けない文章を読みたがります。」
  作品名『飲まないまま』 #AI編集部 （結果のURL）」
- 告知ツイートのURLは投稿文に入れない。入れるとXがそれを引用ツイートとして表示して、結果の画像カードが出なくなる。
  告知ツイートは入口の「告知を見る」から開ける。
- 結果のURLを開くと、投稿に画像が付く。「画像を保存する」はその画像を開く。共有ができる端末では「共有する」も出る。
- 本文はこの画面にも出さない。引用の一文だけ。
- 「別の雑誌に送る」を押すと2に戻る。原稿はこの端末の下書きに残っているので、貼り直さなくてよい。

## 6. 表紙（/cover と /screen）

ブースの大画面（/screen）で全画面表示する。3誌の表紙が並んで浮かんでいる。真ん中が大きい。

```
+--------------------------------------------------+
|  NEW 『毛布いりますか』終電のがし（GEMINI 巻頭）…（流れる）|
|                                                  |
|   +------+   +----------------+   +------+       |
|   |季刊  |   |                |   |月刊  |       |
|   |フェー|   |   GEMINI       |   |アスト|       |
|   |ブル  |   |  （真ん中の1冊は |   |ラ    |       |
|   |      |   |   画面の高さの   |   |      |       |
|   +------+   |   8割ほど）      |   +------+       |
|              +----------------+                  |
|  （編集後記。発行したあとだけ）                    |
|  目次（真ん中の雑誌の全員、ゆっくり流れる）        |
|  [QR: 持ち込みはこちら]    2026年10月号  組版中    |
+--------------------------------------------------+
```

- 10秒ごとに自動で更新する。表紙に入った作品は1回光り、目次に下がった作品は表紙から静かに消える。
- 真ん中の雑誌は30秒ごとに入れ替わる。
- 下に流れる目次は、真ん中の雑誌の表紙の10枠と目次を合わせた全員。
- 右下に「組版中」と出る。発行したら「発行」に変わり、それ以降は変わらない。
- 脇に、表紙の決まり（3誌とも10枠、点数の高い作品が入ると下の作品は目次に移る）と、今日の持ち込み数、今日いちばん多かった理由を出す。発行したあとは、真ん中の雑誌の編集者の編集後記も出る。
- 今はCSSの3Dで作っている。three.jsにするかはまだ決めていない（docs/plan.md）。

スマホで開いたとき（/cover）は、3誌を横に切り替えて見る。

- 表紙の下にその雑誌の目次が縦に並び、「ペンネームで探す」で自分の名前を探せる。
- 自分の作品は表紙の上で光り、「あなた」の印が付く。目次でも同じ印。3誌の切り替えボタンにも、自分の作品がある雑誌に点が付く。
- 開くと、自分が最後に送った雑誌が最初に出る。
- 表紙の作品名は、9字以上と13字以上で文字を小さくして、途中で折れないようにしている。
- 巻末の帯は3誌とも同じ形（「巻末」の見出しと『作品名』作者名の横並び）。

## 7. 目次（/toc）

独立した画面は作らず、/cover に飛ばす。目次は6の表紙の下にある。
作者名と作品名の一覧で、雑誌ごとに分かれている。表紙に載っている作品には枠（例: 特集）が添えてある。

## 9. 管理（/admin）

合言葉を入れると開く。あなたしか使わない。

```
+----------------------------------+
|  管理                            |
|                                  |
|  受付      [受付中] / [受付終了] |
|  上限回数  [3000]  今日 287回    |
|                                  |
|  告知ツイートのURL               |
|  [https://x.com/....        ]    |
|  [保存]                          |
|                                  |
|  編集者                          |
|  季刊フェーブル 蔵人 [出勤]/[休業] 今日 98回  エラー 0回 |
|  GEMINI 二ナ [出勤]/[休業] 今日 121回 エラー 2回 |
|  月刊アストラ  ソル [出勤]/[休業] 今日 68回  エラー 0回 |
|                                  |
|  最近の結果                      |
|  13:42 二ナ 巻頭 『毛布いりますか』終電のがし [表紙から外す] |
|  13:41 蔵人 巻末 『失敗のほう』夕焼け        [表紙から外す] |
|  ...                             |
|                                  |
|  発行  [表紙を固める]            |
+----------------------------------+
```

- 図にないものも並んでいる。同じ回線から1時間に送れる回数（既定0で見ない）、号の名前、「CORE:」に会社名だけ出すかモデル名まで出すか、編集者ごとの厳しさ（甘め、ふつう、厳しめ）、編集後記の書き直し。
- 上限回数に数字以外を入れると、保存せずに「数字を入れてください」と出る。
- 「表紙から外す」は、変な名前や内容が表紙に出てしまったときの手動の逃げ道。
  結果のページは残るが、表紙からは消える。
- ここは見た目にこだわらない。動けばよい。

## 絵が要るもの

docs/image-prompts.md の通り。顔の絵が届くまでは、名前の1文字で動かす。空間はCSSで描いている。
