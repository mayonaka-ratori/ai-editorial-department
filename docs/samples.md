# 結果の例（同じ原稿を3人に見せたとき。第2版）

アプリの画面に実際に出る長さと形で書いています。
文はあくまで例で、実際にはAIが毎回作品に合わせて書きます。
3人の言葉は、人間が一度読んでわかる平易な日本語にします。

## 持ち込み原稿（作者名: 終電のがし、約200字）

> 金曜の夜、終電を逃して漫喫に泊まった。フラットシートは足が伸ばせなくて、隣のブースの人が延々とポテトを食べる音がしていた。三時ごろ、受付の人が「毛布いりますか」と回ってきた。いらないと言ったのに置いていった。朝、毛布をたたんで返したら、たたまなくていいんですよと言われた。駅まで歩く途中、コンビニでホットの緑茶を買って、飲まないまま持って帰った。

## 季刊フェーブル（蔵人）に送った場合

```
季刊フェーブルの蔵人が読みました

引用
「飲まないまま持って帰った」

先に言っておくと、終電を逃して漫喫に泊まる話は、うちの読者はもう何度も読んでいます。
ただ、最後の「飲まないまま持って帰った」は、そうなるとは思いませんでした。ここがいいです。
なぜ飲まなかったのかを書いていないので、読者は続きを自分で想像するしかありません。
うちの読者は、自分では書けない文章を読みたがります。
だから特集にします。
もし毛布の話のほうが本題なら、私の読み方が間違っています。

判定: 特集
作品名: 『飲まないまま』
次は: 今回のように、理由を書かないで終わる話をもう1本お願いします。

二ナ「蔵人さんが特集を出すのは珍しいです！高い評価ですよ！」
ソル「私も同じくらいの評価です。」
```

## 月刊アストラ（ソル）に送った場合

読んでいる間の表示: 「読んでいます」「要点を2つにまとめています」「結論から書いています」

```
月刊アストラのソルが読みました

引用
「たたまなくていいんですよ」

結論から言うと、巻末です。
理由は2つあります。
1つ目。この話を誰に向けて書いたのかが、最後までわかりません。受付の人に向けた話でも、隣の人に向けた話でもありません。誰にも向けていない文章なら、うちの読者は自分で書けてしまいます。
2つ目。「たたまなくていいんですよ」だけは、人が人に向けて言った言葉です。ここだけは、読んでいて次が予想できませんでした。
全部で7つの文のうち、4つは次にどうなるか予想がつきました。

判定: 巻末
作品名: 『たたまなくていい』
次は: この夜のことを、誰か1人に話しかける形で書き直してください。その1人は、緑茶を渡したかった人がいいと思います。

二ナ「ソルさんはいつも巻末ですね！」
蔵人「ソルさんは厳しいので、ソルさんの巻末は、私なら特集くらいの評価です。」
```

## この例からわかる決めごと

- 3人の言葉は、人間が一度読んでわかる平易な日本語にする。省略や体言止めで推測させない。
  理由は「〜なので、〜です」と全部言う。
- 性格の違いは、言葉の難しさではなく、話す順番と口調と見るところで出す。
  蔵人は断ってから話す。二ナはほめてから話す。ソルは結論から話す。
- コメントは200字前後。スマホで1画面に収まる長さ。
- 引用が先に出て、コメント、判定の判子、作品名、次のお願い、の順。
- 見なかった2人のひとことは定型文で、判定の枠ごとに数本ずつ用意しておく。これも平易な日本語で。
- 投稿文には、コメントの中で「うちの読者」の話をしている40字以内の一文を1つ入れる（プログラムが選ぶ）。
- 二ナの豆知識は、間違いようのない当たり前のことにする。「毛布はたたんでも毛布」のような。
  数字や統計を言わせると作り話になるので言わせない。
