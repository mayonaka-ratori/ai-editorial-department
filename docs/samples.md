# 結果の例（同じ原稿を3人に見せたとき）

アプリの画面に実際に出る長さと形で書いています。
文はあくまで例で、実際にはAIが毎回作品に合わせて書きます。

## 持ち込み原稿（作者名: 終電のがし、約200字）

> 金曜の夜、終電を逃して漫喫に泊まった。フラットシートは足が伸ばせなくて、隣のブースの人が延々とポテトを食べる音がしていた。三時ごろ、受付の人が「毛布いりますか」と回ってきた。いらないと言ったのに置いていった。朝、毛布をたたんで返したら、たたまなくていいんですよと言われた。駅まで歩く途中、コンビニでホットの緑茶を買って、飲まないまま持って帰った。

## 曽根蔵人に見せた場合

読んでいる間の表示: 「慎重に読んでいます」「2回目を読んでいます」「言い方を考えています」

```
曽根蔵人が読みました

引用
「飲まないまま持って帰った」

先にお断りしておくと、終電と漫喫までは、うちの読者がもう何度も読んでいる入りです。
ただ、「飲まないまま持って帰った」は読めませんでした。ここは、いいと思います。
買った理由を書かずに終わるので、読者はこの先を自分では書けません。
特集で。
もちろん、毛布のほうが本題だという読み方もあると思います。

判定: 特集
作品名: 『飲まないまま』
次は: 緑茶を買った理由を、書かないまま終わるものをお待ちしています。

二ナ「曽根さんが特集！かなり高いです！」
ソル「妥当だと思います。」
```

投稿文の例:
「月刊フェーブル編集部に持ち込んだら、曽根蔵人が特集にしてくれました。作品名『飲まないまま』 #月刊フェーブル」

## 慈見二ナに見せた場合

読んでいる間の表示: 「素晴らしい原稿を読んでいます！」「関連情報を調べています（調べなくていい）」「話を戻しています」

```
慈見二ナが読みました

引用
「隣のブースの人が延々とポテトを食べる音がしていた」

こういうのが読みたかったんです！
「延々とポテトを食べる音」、これです！足が伸ばせないシートで、三時に起きてる人にしか書けません！
ちなみに毛布は、たたんでもたたまなくても毛布です。話を戻します！
うちの読者には体がないんで、飲まないまま持って帰ったホットの緑茶の温度、大喜びです！
巻頭でいきましょう！
作品名は『毛布いりますか』か『ホットの緑茶』で迷いました。やっぱり前者で！

判定: 巻頭
作品名: 『毛布いりますか』
次は: その緑茶を結局どうしたかまでお待ちしています！

曽根「二ナさんの巻頭は、半分に割って読んでください。」
ソル「記録しておきます。」
```

投稿文の例:
「月刊フェーブル編集部に持ち込んだら、慈見二ナが巻頭にしてくれました。作品名『毛布いりますか』 #月刊フェーブル」

## 明日虎ソルに見せた場合

読んでいる間の表示: 「読んでいます」「要点を2つにまとめています」「結論から書いています」

```
明日虎ソルが読みました

引用
「たたまなくていいんですよ」

結論から言うと、巻末です。
理由は2点です。
1点目、この夜のことを誰に話しているのかが、最後まで決まっていません。受付の人にも、隣のブースの人にも向いていません。うちの読者は、誰にも向いていない文章なら自分で書けます。
2点目、「たたまなくていいんですよ」は、この文章の中で唯一、誰かが誰かに向けて言った言葉です。そこだけは読めませんでした。
予測できた文は7文中4文でした。

判定: 巻末
作品名: 『たたまなくていい』
次は: この夜のことを、緑茶を渡したかった1人に向けて書いてください。

二ナ「ソルさん、いつも巻末ですね！」
曽根「ソルさんの巻末は、私の特集くらいの意味です。」
```

投稿文の例:
「月刊フェーブル編集部に持ち込んだら、明日虎ソルが巻末にしてくれました。作品名『たたまなくていい』 #月刊フェーブル」

## この例からわかる決めごと

- コメントは200字前後。スマホで1画面に収まる長さ。
- 引用が先に出て、コメント、判定の判子、作品名、次のお願い、の順。
- 見なかった2人のひとことは定型文で、判定の枠ごとに数本ずつ用意しておく。
- 二ナの豆知識は、間違いようのない当たり前のことにする。「毛布はたたんでも毛布」のような。
  数字や統計を言わせると作り話になるので言わせない。
