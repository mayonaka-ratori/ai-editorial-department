# Codexへの指示（宣伝画像を作る。全部入り）

リポジトリをつながずに使う版です。「---」の間を丸ごとCodexに貼り、参照画像のzip（promo-refs.zip）を一緒に添付してください。
zipの中身は docs/archive/guide-images と public/covers の画像です。

---

Xに投稿する宣伝画像を作ってください。画像生成には gpt-image-2.5 を使ってください。
宣伝するのは「AI編集部」というWebアプリです。中身を先に説明します。

## アプリの説明（絵を作るときの前提）

- 「AIが読む小説雑誌」を作っている編集部、という設定のWebアプリ。来場者が自分のスマホで、自分の文章を送る。
- 雑誌は3つ。雑誌ごとにAIの編集者が1人いる。編集者が文章を読んで「うちの読者（AI）にウケるか」を判定する。判定は上から、巻頭、特集、巻末、名前だけ、次号待ち、の5段階。
- 結果が良いと、作品名とペンネームが雑誌の表紙に載る。表紙はブースの大画面にも出る。
- 体験は2分、無料、スマホだけで遊べる。
- 3つの雑誌の見た目。
  - 季刊フェーブル: 生成りの紙に橙の罫線。橙の四角の中で、本の上に座って本を読む炎の子のイラスト。色は橙と黒。
  - GEMINI: パステルの水彩の地。虹色のリボンに乗った毛玉のマスコット。色とりどり。
  - 月刊アストラ: 太陽、月、地球と軌道の線が入った宇宙。色は深い紺。
- アプリの画面は、深い紺の地に水色の線と六角形の模様が入った、明るい近未来の空間。判定の印は六角形で、巻頭のときだけ金色に光る。

## 添付した参照画像

添付できたら、生成のときに参照画像として渡してください。添付がない場合は、上の説明を指示文に足して作ってください。

- kurodo-bg.webp: 季刊フェーブルの表紙の絵。
- nina-bg.webp、nina-logo.webp、nina-mascot.webp: GEMINIの表紙の地、ロゴ、マスコット。
- sol-bg.webp: 月刊アストラの表紙の絵。
- 08-screen.jpg: ブースの大画面。3冊の表紙が並んで浮かんでいる。案Aの構図の見本。
- 06-result-nina.jpg: スマホの結果の画面。金色の六角形の印。案Cの構図の見本。

## やること

1. 文字の入っていない絵を gpt-image-2.5 で作り、promo/raw/ に保存する。
2. その絵に日本語の文字を重ねた完成画像を作り、promo/ に保存する。
3. 完成画像の一覧と、確認してほしい点を最後に報告する。

## 絵を作るときの共通の決まり

- 絵の中に文字、ロゴ、数字を入れない。文字はあとから重ねる。
- 大きさは、16:9の絵は1600×900以上、1:1の絵は1080×1080以上。
- 1つの案につき2枚ずつ作り、良いほうを残す。
- 実在の人物、既存のキャラクター、既存の企業のロゴやマスコットに似せない。

## 文字を重ねる

- 方法: 絵を背景にしたHTMLを1枚書き、ヘッドレスのブラウザ（PlaywrightかPuppeteer）でPNGに撮る。画像編集ライブラリで文字を描かない（日本語が崩れやすいため）。
- 書体: Google Fonts の Zen Kaku Gothic New（太さ900と500）と Rajdhani（太さ700）を使う。ダウンロードして @font-face で読み込むか、Google Fonts のCSSを読み込む。中国語の字体が混じらないように、font-family の先頭に必ず Zen Kaku Gothic New を置き、lang="ja" をhtmlに付ける。
- 色: 文字は白。暗い絵の上では白のまま。明るい絵（案C、案E）の上では、文字の下に黒の半透明（不透明度40%）の帯を敷く。
- 大きさ: 1600×900の絵で、大きい文は72px、小さい文は32px、一番下の文は24px。1080×1080の絵では、それぞれ60px、28px、22px。
- 位置: 指示文で空けた場所に置く。案Aの16:9は左、案Aの1:1は下、案Cは左右どちらか、案Eは上。端から最低80pxは空ける。
- 文は次のとおり。1文字も変えない。

| 絵 | 大きい文 | 小さい文（2行） | 一番下 |
|---|---|---|---|
| a-16x9、a-1x1 | AIが読む小説雑誌に、あなたの文章を持ち込む。 | 体験2分、無料。スマホだけで遊べます。／雑誌は3つ。編集者は3人。判定はばらばらです。 | AI編集部　AIが読む小説雑誌を作っています |
| c-16x9 | あなたの文章、AI編集者が2分で判定します。 | 巻頭になると、表紙とブースの大画面に名前が出ます。／無料。 | AI編集部　AIが読む小説雑誌を作っています |
| e-16x9 | AIには書けない文章を、探しています。 | 体験2分、無料。スマホだけで遊べます。 | AI編集部　AIが読む小説雑誌を作っています |

- 「／」は改行の印。文の中には入れない。
- 「AI編集部　AIが読む小説雑誌を作っています」の間は全角スペース。
- c-16x9 だけ、六角形の真ん中に「巻頭」の2文字を Zen Kaku Gothic New の900の白で重ねる。大きさは六角形の高さの3分の1。

保存先: promo/a-16x9.png、promo/a-1x1.png、promo/c-16x9.png、promo/e-16x9.png

## 最後に報告すること

- 作った画像のパスの一覧。
- 各画像の大きさとファイルサイズ（5MB以下であること）。
- 文字の「直」「関」「込」「持」が日本語の字体になっているか、拡大して確かめた結果。
- 参照画像のマスコットや表紙が、元の絵から変わっていないか。変わっていたら、どこが変わったか。
- 生成に使った最終の指示文（直した場合はその文）。

## やらないこと

- 絵の中に文字を生成させない。
- 添付した参照画像そのものを書き換えない。
- 完成画像をJPEGにしない。PNGのまま。
